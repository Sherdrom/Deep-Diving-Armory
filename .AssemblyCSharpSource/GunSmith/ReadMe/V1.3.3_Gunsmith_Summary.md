# Gunsmith V1.3.3 Summary

V1.3.3 finalizes HK416 hidden quick slots as real Barotrauma container slots while adding conditional visibility and logic-level drag/drop protection.

## Completed

- Added conditional quick slot visibility.
  - HK416 slot `1` can now be shown when it contains `deep_sub_hanging_m203` or `deep_sub_hanging_master_key`.
  - The rule is configured in Lua with `showWhenContained`.
  - Other managed quick slots remain hidden unless explicitly configured.
- Split managed slot registration from conditional visibility rules.
  - `DeepGunsmithRegisterHiddenQuickSlots` still registers GunSmith-managed quick slots.
  - `DeepGunsmithRegisterQuickSlotVisibility` registers per-slot contained-item visibility rules.
  - C# keeps managed slot data and visibility rules separate to avoid the earlier issue where every quick slot became visible.
- Added logic-level managed slot blocking.
  - Hidden slots are no longer only visually hidden.
  - `ItemInventory.FindAllowedSlot` skips managed quick slots during normal drag/drop auto-placement.
  - Direct `ItemInventory.TryPutItem` into managed slots is blocked unless the operation is an authorized GunSmith QuickMod mutation.
  - Non-managed slots such as HK416 magazine slot `0` and chip slots `6-7` keep normal behavior.
- Added QuickMod mutation guard.
  - Lua wraps QuickMod container writes with `DeepGunsmithBeginQuickSlotMutation` and `DeepGunsmithEndQuickSlotMutation`.
  - Quick UI installation/removal can still write real slot `1-5` container items.
  - Normal player drag/drop cannot bypass the quick UI to install or replace quick attachments.
- Preserved underbarrel weapon sub-inventory behavior.
  - When a visible managed slot contains a weapon with its own inventory, compatible items can still be routed into that child inventory.
  - This allows Masterkey/M203 ammo loading while keeping the underbarrel attachment itself managed by GunSmith.

## Notes

- V1.3.3 keeps HK416 original XML gameplay effects as the authority.
- The quick attachments are still real contained items, so `RequiredItems type="Contained"` behavior remains intact.
- `showWhenContained` controls visibility only; it does not grant permission to install or replace quick attachments through vanilla drag/drop.
- This version only validates the behavior on `deep_hk416`.

## Validation

- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` completed with 0 errors.
- Local `luac -p` validation could not be run because `luac` was not available on PATH.
- In-game testing confirmed:
  - HK416 quick slots `1-5` stay hidden unless conditionally visible.
  - Masterkey/M203 in slot `1` can reveal the underbarrel slot and expose its child inventory.
  - Ammo can be dragged into the visible underbarrel weapon inventory.
  - Normal drag/drop cannot install or replace HK416 quick attachments.
  - Magazine and chip slots keep normal behavior.
