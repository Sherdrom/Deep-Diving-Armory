# Gunsmith V1.3.2 Summary

V1.3.2 returns HK416 quick-mod to the stable original-XML effect path while moving player interaction to a dedicated GunSmith quick-mod UI.

## Completed

- Kept HK416 original ItemContainer-backed gameplay behavior.
  - HK416 quick attachments still occupy the original contained slots.
  - Original XML `RequiredItems type="Contained"` effects remain the authority for muzzle, sight, side rail, and underbarrel behavior.
  - No C# gameplay bridge or `SwitchableRangedWeapon` behavior migration is included in this version.
- Added dedicated quick-mod UI support.
  - `Shift+G` opens the quick-mod UI for weapons with `quickSlots`.
  - `G` continues to open the full GunSmith UI.
  - The quick UI shows only configured quick attachment paths and uses the same selection, compatibility, inventory consumption, return, save, and apply flow as GunSmith.
  - Quick UI refreshes in place through `DeepGunsmithRefreshQuick` instead of reopening the full window.
- Added `QuickUiSpec.lua`.
  - Quick UI slot data is generated from `weapon.quickSlots`.
  - Slot display names can use per-quick-slot `nameKey`.
  - Part availability is based on GunSmith selection and player inventory checks, not the weapon's own hidden attachment inventory.
- Added generic hidden quick slot registration.
  - Lua registers every weapon's `quickSlots` with C# through `DeepGunsmithRegisterHiddenQuickSlots`.
  - The C# hidden-slot patch is weapon-agnostic and keyed by item identifier.
  - HK416 currently registers slots `1-5` as managed quick slots.
- Added hidden quick slot inventory patching.
  - Managed quick slots are hidden from the original Barotrauma item inventory.
  - Visible slots are packed forward so non-managed slots keep a compact layout.
  - Sub-inventory layout is packed after Barotrauma positions the item inventory, so hover, drag, and drop use the same slot coordinates that are drawn.
  - Hidden quick slots remain real container slots, so original XML effects still work.
- Updated HK416 quick slot metadata.
  - HK416 quick slot entries now include `nameKey` for quick UI labels.
  - `order` is not used; quick UI order follows the Lua array order.
- Added Chinese localization for quick UI labels.
  - `deep.gunsmith.ui.quick_title`
  - `deep.gunsmith.ui.quick_root`

## Notes

- V1.3.2 only finalizes the hidden-container plus quick-mod UI route for HK416.
- The earlier dynamic ItemContainer and C# gameplay migration approaches were abandoned for this version.
- The proposed `showWhenContained` behavior was not kept in this version and remains a follow-up design topic.
- Quick slots are still real Barotrauma container slots; the player-facing restriction is that they are managed through GunSmith quick UI instead of manual drag/drop.
- M4 dynamic container work is not included in this version.

## Validation

- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false /p:ModDeployDir=.buildcheck\` completed with 0 errors.
- Local `luac -p` validation could not be run because `luac` was not available on PATH.
- In-game testing confirmed hidden quick slots can be packed without breaking visible slot hover/drag/drop behavior.
- In-game testing confirmed the quick slot hidden/packed inventory path works after removing the experimental `showWhenContained` changes.
