# Gunsmith V1.3 Summary

V1.3 adds the first bridge between GunSmith selections and Barotrauma's original `ItemContainer` workflow. The first validated weapon is `deep_hk416`.

## Completed

- Added the `QuickMod` Lua bridge.
  - HK416 terminal attachment slots can be read from the weapon's original `ItemContainer`.
  - Real contained items are mapped back to compatible GunSmith parts by `item.identifier`.
  - Empty quick-mod slots clear the matching GunSmith selection path.
- Added HK416 quick-slot mapping.
  - Slot 1 maps to `receiver/handguard/Lower_rail_mount`.
  - Slot 2 maps to `receiver/handguard/Right_rail_mount`.
  - Slot 3 maps to `receiver/handguard/Left_rail_mount`.
  - Slot 4 maps to `receiver/optic_mount`.
  - Slot 5 maps to `receiver/barrel/muzzle_mount`.
- Updated GunSmith runtime flow.
  - `Runtime.Apply` and `Runtime.Open` synchronize quick-mod slots before composing sprites or building the UI spec.
  - GunSmith GUI installation for quick-mod paths now routes through the HK416 `ItemContainer`.
  - Deep-mod structural parts still use the existing GunSmith inventory and saved-state path.
- Avoided duplicate visual rendering.
  - HK416 quick-mod `Containable` entries are hidden in the original ItemContainer display.
  - GunSmith remains responsible for the final composed weapon visuals.
- Kept the quick-mod item mapping strict.
  - No alias layer is used.
  - Future left/right variants should be modeled as explicit GunSmith parts or cleaned up in content data.

## Notes

- V1.3 validates the ItemContainer bridge only on `deep_hk416`.
- The original XML behavior still uses real contained items for `RequiredItems` and status effects.
- GunSmith stats remain the source for the composed UI/runtime stat values.
- Original XML remains the source for function-style effects such as thermals, muzzle sound paths, and underbarrel switching.

## Known Issues

- After installing and removing a quick-mod attachment through the GunSmith GUI, the right-side detail panel can fail to refresh immediately and may still show the previous missing-part state.
- This UI refresh issue is intentionally left for the next small version.

## Validation

- In-game testing confirmed that HK416 ItemContainer quick-mod functionality works.
- `luac -p` passed for the updated GunSmith Lua files.
- `xmllint --noout weapon/rifle/rifle_phy/hk416.xml` completed with 0 errors.
- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` completed with 0 errors.
- Existing `ILuaCsHook.Add` deprecation warnings remain.
