# Gunsmith V1.2 Summary

V1.2 establishes the GunSmith localization foundation. The goal is to keep future weapon and part content from scattering display text across Lua config and C# UI code.

## Completed

- Converted GunSmith Lua display fields to localization keys.
  - `part.name` is replaced by required `part.nameKey`.
  - `mount.name` is replaced by optional `mount.nameKey`.
  - `platform.pathNames` is replaced by `platform.pathNameKeys`.
- Updated Lua UI spec output to send text keys instead of resolved Chinese strings.
- Updated the C# GunSmith UI to localize all visible labels through `TextManager.Get(...).Fallback(...)`.
- Added Chinese GunSmith text entries to `text/chinese.xml`.
- Kept English optional for this version; missing English keys fall back safely.
- Updated validation for removed fields and required localization key fields.

## Notes

- V1.2 only covers the GunSmith system, not the whole mod.
- XML item prefab `name` fields are not part of this version's localization pass.
- New content should add a `nameKey` for every part and add the Chinese text key at the same time.

## Validation

- `text/chinese.xml` parses as XML.
- Runtime/config `deep.gunsmith.*` keys are present in `text/chinese.xml`.
- `GunsmithGui.cs` no longer contains player-visible Chinese literals.
- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` completed with 0 errors.
