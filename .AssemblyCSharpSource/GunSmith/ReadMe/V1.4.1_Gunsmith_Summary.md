# Gunsmith V1.4.1 Summary

V1.4.1 focuses on polishing the full `G` GunSmith panel after the V1.4 stat migration. The full modification UI now follows a more Barotrauma-native list style, shows real attachment icons, and keeps the selected attachment detail panel compact enough for dense stat sets. QuickMod is intentionally left for the next small version.

## Completed

- Reworked the full `G` modification panel presentation.
  - Replaced button-like slot and part entries with stable list rows.
  - Left slot navigation now uses highlight color for selection instead of adding a `[selected]` text prefix.
  - Left and right list titles now share the same row sizing so the two panels read consistently.
  - Part list rows show an icon, localized name, status text, hover state, and selected highlight.
  - List state still uses the existing `available`, `installed`, `missing`, `incompatible`, and `disabled` logic; install behavior was not changed.

- Improved selected attachment detail display.
  - The right detail panel now uses a compact preview-and-text layout.
  - Attachment preview is rendered from the item prefab inventory icon when available, with Lua visual texture/source fallback.
  - Preview images are shown inside a square frame with an outline.
  - Descriptions were removed from this pass because the small detail panel does not have enough reliable space for readable long text.
  - Non-zero `part.stats` values remain the main detail text.

- Fixed part selection and install refresh behavior.
  - Selecting another part after installing no longer leaves the bottom action button bound to stale data.
  - Installed/missing/actionable status is refreshed from the latest slot state.
  - The selected row and selected detail panel stay in sync after install, replacement, and refresh.

- Added window behavior closer to Barotrauma panels.
  - GunSmith windows can be dragged by the top area.
  - Right-clicking inside the window closes it.
  - UI refresh errors are caught and close the panel instead of crashing the client.

- Extended UI spec data for icon rendering.
  - `UiSpec` now sends part item identifier, visual texture path, and visual source rectangle.
  - C# resolves `ItemPrefab` by item identifier before falling back to configured visual source data.
  - Text encoding was added to avoid delimiter collisions in the Lua-to-C# UI spec payload.

- Cleaned localization and validation.
  - Removed the unused `deep.gunsmith.ui.selected_prefix` key from validation and Chinese text.
  - Kept existing stat/localization validation in place for GunSmith startup checks.

## Deferred

- Final `Shift+G` QuickMod redesign.
  - Current code has early quick-slot metadata and anchor parsing support, but the final quick inventory/drop-slot workflow is deferred.
  - The next version should build QuickMod around a separate inventory-style drop area instead of disturbing the existing hidden ItemContainer bridge.

- Rich attachment descriptions.
  - Description text is not shown in V1.4.1 because it was too small and visually noisy in the current right detail panel.
  - A larger inspection panel can be revisited if the full UI layout changes again.

- Further UI polish.
  - Automatic row filtering/search.
  - More complete keyboard/gamepad navigation.
  - More robust quick-slot line/box avoidance for dense attachment layouts.

## Compatibility Notes

- V1.4.1 does not change the V1.4 `part.stats` authority model.
- Existing inventory consumption, install/removal rules, and compatibility checks are preserved.
- Non-GunSmith weapons and old XML affliction behavior are unaffected.
- QuickMod behavior is not considered finalized in this version.

## Validation

- `dotnet build .AssemblyCSharpSource/GunSmith/ClientProject/WindowsClient.csproj -c Debug -m:1 /p:Platform=x64 /p:UseSharedCompilation=false /p:ModDeployDir=.buildcheck\` completed with 0 errors.
- Existing `ILuaCsHook.Add` deprecation warnings remain.
- In-game UI iteration confirmed the G panel no longer uses button-like part rows, attachment icons render, right detail layout is readable, and stale install button state was fixed.
