# Gunsmith V1.4.3 Summary

V1.4.3 finalizes the current QuickMod UI polish pass. This version fixes the remaining quick-slot drag loss cases, stabilizes the quick weapon preview, keeps inventory icons on their original content-bound behavior, and splits the large C# GUI implementation into focused partial files.

## Completed

- Fixed QuickMod drag/drop item loss edge cases.
  - Failed drops onto quick slots now restore pending quick-dragged attachments to their original weapon slot.
  - Releases outside actual quick slot boxes now fall through to Barotrauma's normal outside-inventory drop logic.
  - The quick overlay background no longer consumes dragged item releases as an inventory target.
  - Quick inventory mouse interception now only applies to real quick slot rectangles.

- Stabilized the QuickMod weapon preview.
  - The quick weapon image now uses a fixed composed-canvas source frame instead of resizing around the current visible attachments.
  - Preview centering is based on stable weapon body bounds, excluding quick-slot attachment layers that can be added or removed.
  - Adding or removing quick attachments no longer shifts the main weapon body around the overlay.

- Refined quick slot display positioning.
  - C# applies small display offsets around resolved GunSmith mount anchors.
  - Offset rules are based on generic path fragments such as optic, rail, and muzzle mounts, rather than one exact weapon path.
  - Lua anchor/config data remains the initial structural truth and was not modified for this UI polish pass.

- Split the Gunsmith GUI implementation.
  - `GunsmithGui` now lives in its own `ClientSource/GunsmithGui` folder.
  - Parsing, formatting, visual helpers, quick overlay code, and shared GUI types were moved into focused partial class files.
  - Public hook behavior and Lua data formats remain unchanged.

- Kept inventory icon behavior stable.
  - Weapon inventory icons were returned to their original content-bound sizing behavior.
  - The fixed canvas/centering behavior is limited to the QuickMod overlay preview.

## Compatibility Notes

- Existing Lua weapon and part configuration formats are unchanged.
- GunSmith mount anchors remain compatible with the current quick slot resolver.
- Hidden weapon slots remain the authoritative storage for installed quick attachments.
- Existing Lua and Harmony entrypoints continue to call the C# GUI through the renamed `GunsmithGui` class.
- Non-QuickMod inventory icon composition is not intentionally changed in this version.

## Validation

- Source build verified with a temporary deploy directory:
  - `dotnet build .AssemblyCSharpSource/GunSmith/ClientProject/WindowsClient.csproj -c Release -p:Platform=x64 -p:ModDeployDir=.buildcheck\`
- The temporary deploy directory avoids failures when the live Barotrauma client has `bin/Client/Windows/GunSmith.dll` locked.
- Existing `ILuaCsHook.Add` deprecation warnings remain acceptable if emitted by the local toolchain.
