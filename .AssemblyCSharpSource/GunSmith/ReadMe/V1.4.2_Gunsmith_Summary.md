# Gunsmith V1.4.2 Summary

V1.4.2 focuses on the `Shift+G` QuickMod panel. This version keeps the hidden weapon slots as the authoritative storage, adds a lighter quick overlay with slot boxes derived from GunSmith mount anchors, and establishes the first usable drag/drop path for quick attachments. The remaining item-loss edge cases are explicitly deferred for the next pass.

## Completed

- Added a dedicated QuickMod overlay for `Shift+G`.
  - The quick UI no longer reuses the full three-column `G` panel.
  - The current composed GunSmith weapon sprite is rendered as the main background preview.
  - Quick slot boxes are generated from `quickSlots` metadata and resolved mount anchors.
  - Slot boxes draw connector lines back to the gun attachment anchor.
  - The quick preview uses its own scale/layout rules so the full `G` panel preview is not affected.

- Improved quick slot layout.
  - Lower rail slots are placed below the weapon.
  - Left and right rail slots are offset to avoid complete overlap when their anchors share the same mount position.
  - Muzzle, optic, and other slots continue to use automatic placement around their resolved anchor.
  - Slots with unresolved anchors fall back to a safe preview-edge position and log a warning.

- Implemented lightweight virtual quick slot interaction.
  - Quick slots are drawn as virtual UI hitboxes, not as persistent UI-only inventories.
  - Dragged items are checked against the quick slot compatible item identifiers.
  - Accepted items are moved into the weapon's real hidden `OwnInventory` slot.
  - Failed drops keep the dragged item active and show quick red feedback instead of intentionally clearing the drag state.
  - Installed quick parts are displayed using the part icon path already used by the full panel.

- Preserved hidden slot behavior.
  - The existing hidden ItemContainer bridge remains the final storage path.
  - Managed hidden slots stay hidden from normal inventory layout unless their `showWhenContained` rule applies.
  - Direct normal inventory auto-put avoids managed quick slots.
  - C# quick mutations are marked so Lua `OnItemContained` / `OnItemRemoved` sync does not run in the middle of a controlled quick slot move.

- Added lightweight container sync for QuickMod.
  - Lua hook `DeepGunsmithSyncQuickContainer` syncs current hidden slot contents back into GunSmith selection.
  - The sync path applies selection changes, saves persistence, reapplies sprite/runtime stats, and refreshes quick UI.
  - This path does not use `QuickMod.ClearSlot` and does not spawn/remove replacement prefab items.

- Kept GunSmith window input shielding.
  - Quick and full GunSmith windows block mouse-driven background interactions.
  - Keyboard movement remains available while the window is open.
  - Right-click close and close-button behavior remain available through the GunSmith window frame.

## Deferred

- Remaining item-loss and drag ownership edge cases.
  - Some quick drag paths still need a more robust ownership transaction model.
  - Replacing items, dragging out then closing the UI, and unusual inventory/drop paths should be revisited separately.
  - The current version deliberately keeps the simpler pre-transaction behavior after the attempted transaction layer was rolled back.

- Full parity with vanilla inventory drag feel.
  - Quick slots are still virtual hitboxes, not true inherited vanilla inventory slots.
  - Hover, cursor, and drop feedback are usable but not fully identical to Barotrauma's native inventory UI.

- Multiplayer authority.
  - QuickMod remains a client-focused workflow in this version.
  - Server-side authoritative quick state synchronization is still outside the V1.4.2 scope.

## Compatibility Notes

- XML hidden slot containment remains the final rule for what can actually live in weapon quick slots.
- HK416/M4 `RequiredItems type="Contained"` behavior continues to rely on the real hidden weapon slots.
- Non-GunSmith weapons and ordinary item containers are not intentionally changed.
- V1.4 `part.stats` remains the GunSmith attribute authority model.
