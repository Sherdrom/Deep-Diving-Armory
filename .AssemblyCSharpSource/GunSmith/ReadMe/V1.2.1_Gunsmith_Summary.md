# Gunsmith V1.2.1 Summary

V1.2.1 adds the first gameplay-facing GunSmith stat: ergonomics. The scope is deliberately narrow: ergonomics only affects the local player's weapon raise speed when starting to aim.

## Completed

- Added runtime stat delivery from Lua GunSmith selections to the C# client.
  - Lua now sends the composed selection's total stats through `DeepGunsmithApply`.
  - C# stores the parsed values in `GunsmithRuntimeStats`.
- Added default gameplay stats for the current AR test weapons and parts.
  - M4 and HK416 now provide baseline ergonomics values.
  - Existing part stats contribute to the final runtime total.
- Added local-player ergonomics handling in `GunsmithErgonomicsAimPatch`.
  - The patch targets `Holdable.Update(float, Camera)`.
  - Only local, controlled characters holding a GunSmith ranged weapon are affected.
  - Non-GunSmith weapons, AI, and remote players use the original game behavior.
- Implemented weapon raise delay through the original hold animation path.
  - During the raise phase, GunSmith temporarily handles the hold frame and calls `AnimController.HoldItem(...)`.
  - The weapon transitions from `HoldPos` toward `AimPos`.
  - The virtual aim target interpolates from the current weapon direction toward the live cursor direction.
  - After the raise phase ends, the original `Holdable.Update` logic takes over again.
- Removed failed prototype approaches.
  - Direct `crosshairPos` manipulation was removed.
  - Direct `item.body` rotation control was removed.
  - Temporary `Character.CursorPosition` control was removed.
  - `InputType.Aim.Reset()` input-delay behavior was removed.
  - Debug console logging for ergonomics was removed after verification.

## Notes

- V1.2.1 does not implement recoil.
- Ergonomics currently affects only the initial raise-to-aim phase, not sustained mouse tracking.
- `RaiseTravelRadians` in `GunsmithErgonomicsAimPatch.cs` is the main tuning constant for global raise duration.
- The current speed formula is `Clamp(60 + ergonomics * 20, 45, 720)` degrees per second.
- RemainedAmmo does not require changes; after the raise phase, original crosshair behavior is restored.

## Validation

- In-game testing confirmed that ergonomics raise delay is visible and behaves within the intended scope.
- GunSmith debug logs for the ergonomics patch were removed after confirming the patch path.
- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` completed with 0 errors.
- Existing `ILuaCsHook.Add` deprecation warnings remain.
