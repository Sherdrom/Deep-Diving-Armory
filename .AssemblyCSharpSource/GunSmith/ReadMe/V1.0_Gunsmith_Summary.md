# Gunsmith V1.0 Summary

## Goal

V1.0 focuses on content production stability. Instead of adding gameplay systems, this version adds an external visual coordinate tool and a Chinese production guide so new weapons and parts can be authored faster.

## Result

Implemented scope:

- Added `.Tools/GunsmithAnchorEditor/index.html`.
- The tool is a standalone browser HTML file with no dependency install step.
- It can import a sprite sheet, select `visual.source`, set `visual.attachPoint`, set `weapon.rootSockets.receiver`, set child `mount.anchor`, and preview a composed weapon.
- It can save/load editor project JSON.
- It exports Lua snippets for `rootSockets`, `visual`, `mounts`, and a receiver-style part block.
- Added `V1.0_Content_Production_Guide.md` in Chinese.
- Updated the ReadMe index with V1.0 links.

## Stable Workflow

Recommended content workflow:

1. Prepare a sprite sheet.
2. Use the editor to box each part source.
3. Pick attach points on each source.
4. Place the receiver root socket on the platform canvas.
5. Place receiver/parent mount anchors in the preview.
6. Export Lua snippets and paste them into the real config.
7. Validate in-game with `DeepGunsmithValidate`.
8. Tune `preview`, `inventory`, and `world` transforms separately.

## Out Of Scope

- No Lua file parsing or automatic config rewriting.
- No AK implementation.
- No gameplay stat effects.
- No multiplayer authority.
- No workbench entry.
- No final art pass.
