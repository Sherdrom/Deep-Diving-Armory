# Gunsmith V0.6 Summary

## Goal

V0.6 adds the first display-only stat layer and upgrades the GunSmith UI preview.

This version still does not change weapon handling, damage, recoil, reload, multiplayer authority, or workbench flow. Stats are configuration and UI information only.

## Stats

Parts may now declare optional `stats`.

```lua
stats = {
    weight = 0.0,
    ergonomics = 0.0,
    recoilControl = 0.0,
    spreadReduction = 0.0,
    fireRateMultiplier = 0.0,
    damageMultiplier = 0.0
}
```

Missing `stats` is valid and means all stat values are zero.

`Lua/Scripts/Gunsmith/Stats.lua` owns stat reading, summing, and UI protocol encoding. The current weapon total is calculated from all installed parts in the selection, including default, entity-backed, and virtual parts.

## UI

The right-side part list no longer installs parts immediately.

- clicking a part selects it for inspection
- the lower right panel shows the selected part stats
- `安装该配件` / `拆除该配件` performs the actual change
- missing, incompatible, installed, and disabled states still prevent invalid actions

The middle panel now shows:

- current composed gun preview
- current total weapon stats
- current path and enter-mount button

This keeps whole-weapon information in the preview area and candidate-part information in the right panel.

## Preview

The preview uses the current runtime-composed texture, but it no longer relies on `GUIImage` sprite positioning.

C# now tracks each composed layer's `slotPath`, part id, and draw bounds. The union of visible layer bounds becomes the weapon `ContentBounds`.

The preview panel draws the composed texture directly with `SpriteBatch.Draw(...)`, using `ContentBounds` as the source rectangle and the preview panel center as the destination center. This avoids hidden `Sprite`/`GUIImage` origin behavior and keeps the gun centered.

Weapon preview config is now optional fine tuning:

```lua
preview = {
    padding = 12,
    zoom = 1.0,
    offset = { x = 0, y = 0 }
}
```

- `padding` adds space around automatically detected weapon bounds
- `zoom` crops tighter or looser around the weapon bounds
- `offset` nudges the preview source region

The old `preview.origin` / `preview.scale` camera experiment is no longer used.

## Validation

Validation now checks:

- `stats` is a table when present
- known stat fields are numbers
- unknown stat fields produce warnings
- `preview.padding` is non-negative
- `preview.zoom` is positive
- `preview.offset` has numeric `x/y`

No warning is emitted for parts without stats.
