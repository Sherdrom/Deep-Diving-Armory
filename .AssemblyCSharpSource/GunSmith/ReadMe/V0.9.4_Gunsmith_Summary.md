# Gunsmith V0.9.4 Summary

## Goal

V0.9.4 continues the config cleanup started in V0.9.2 and V0.9.3. The goal is to keep platform and weapon visual settings consistent and remove confusing duplicate scale concepts.

## Result

Implemented scope:

- `platform.requiredSlots` now uses hidden-root-relative short paths:
  ```lua
  requiredSlots = {
      "barrel",
      "handguard",
      "pistol_grip",
      "stock"
  }
  ```
- Runtime still stores and operates on full selection paths such as `receiver/barrel`.
- Removed weapon-level `scale`; layer composition now uses `platform.visualScale * part.visual.scale`.
- Renamed UI preview zoom config to `preview.scale`.
- HK416 now declares a normal `preview` block instead of leaving it commented out.
- Validation now errors on removed `weapon.scale`, `preview.zoom`, keyed `requiredSlots`, and full-path `requiredSlots` entries.
- Root slots are now always required, so `rootSlots[].required` is removed.

## Config Semantics

- `platform.visualScale`: platform-level composed layer scale.
- `part.visual.scale`: single part layer scale.
- `preview.scale`: GunSmith UI preview only.
- `inventory.scale`: inventory icon only.
- `world.scale`: hand-held and dropped WorldSprite only.

## Validation

Validation now checks:

- `requiredSlots` must be an array of short path strings.
- `requiredSlots` requires exactly one hidden platform root.
- `requiredSlots` entries must not contain `/`.
- `rootSlots[].required` is a removed field; every root slot must be supplied by `weapon.rootParts` and `weapon.rootSockets`.
- `preview.scale` must be positive when declared.
- `preview.zoom` and `weapon.scale` are removed fields.

## Test Notes

Checked in this version:

- Static search should show no config usage of `weapon.scale =`, `preview.zoom`, or full-path `requiredSlots`.
- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` should pass with only the existing `ILuaCsHook.Add` deprecation warnings.
