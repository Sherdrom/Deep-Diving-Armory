# Gunsmith V1.1 Summary

V1.1 focuses on WorldSprite correctness and config simplification after the V1.0 content-production tooling work. The goal is to make hand-held and dropped weapon sprites stable while keeping per-weapon world tuning practical.

## Completed

- Fixed WorldSprite origin calculation after runtime texture cropping.
  - The composed canvas origin is now mapped into the cropped, scaled, and rotated world texture.
  - Installing tall attachments such as optics no longer shifts the whole held weapon upward.
- Restored `weapon.world.offset` tuning behavior.
  - `offset` now moves the baked world texture content without moving `Sprite.Origin`.
  - This keeps the origin stable while still allowing per-weapon hold/drop visual adjustment.
- Kept inventory icon behavior separate from WorldSprite behavior.
  - Inventory icons continue to use centered baked icon sprites.
  - Inventory tuning remains controlled by `weapon.inventory`.
- Confirmed preview behavior is not a Sprite-origin path.
  - GunSmith preview draws the composed texture directly through GUI source rectangles.
  - Preview centering remains content-based and separate from world origin handling.
- Removed remaining platform-level visual transform fields.
  - `platform.visualScale`, `platform.visualOrigin`, and `platform.worldSpriteDepth` are now treated as removed fields.
  - World sprite depth remains controlled by the original XML `<Sprite depth="...">`.
- Simplified runtime layer output.
  - Layer positions use resolved draw coordinates directly.
  - Per-part layer scale is controlled by `part.visual.scale`.
- Updated HK416 world offset values after in-game verification.
- Updated the anchor editor README to match the current scale rules.

## Notes

- `weapon.world.offset` is a visual bake offset, not an XML `holdpos` replacement.
- XML `holdpos` still controls the character hold position.
- XML sprite `depth` still controls world sprite draw depth.
- Inventory and preview do not currently need the same origin-remapping fix as WorldSprite.

## Validation

- `dotnet build .AssemblyCSharpSource/GunSmith/GunSmith.sln -m:1 /p:UseSharedCompilation=false /p:DebugType=None /p:DebugSymbols=false` completed with 0 errors.
- Existing `ILuaCsHook.Add` deprecation warnings remain.
- During one build, `bin/Client/Windows/GunSmith.dll` was locked by a running Barotrauma process, but the projects compiled successfully.
