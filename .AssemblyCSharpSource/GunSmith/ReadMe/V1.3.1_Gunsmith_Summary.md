# Gunsmith V1.3.1 Summary

V1.3.1 fixes the V1.3 quick-mod UI refresh issue after HK416 ItemContainer-backed attachment changes.

## Completed

- Added ItemContainer Lua patches for quick-mod UI synchronization.
  - Lua patches `ItemContainer.OnItemContained` and `ItemContainer.OnItemRemoved` after the original container mutation.
  - Quick-mod changes now refresh the open GunSmith part list/detail panel from the actual container change event instead of a polling queue.
- Removed the GunSmith `think` refresh/apply scan.
  - Default composed sprites now apply from item lifecycle patches and saved-state receive callbacks.
  - Loaded-map items are handled through `Item.OnMapLoaded`; newly constructed items are handled through an `Item` constructor patch when supported by LuaCs.
- Added a scoped C# UI refresh hook.
  - `DeepGunsmithRefreshParts` updates the active slot data and rebuilds only the right-side part list/detail panel for the current item.
  - The main window, left slot list, and middle preview panel are not rebuilt during quick-mod status refreshes.
- Reduced right-panel flicker during quick-mod status refreshes.
  - The right-side part list/detail panel now updates existing controls in place when the slot and part structure did not change.
  - Full right-panel rebuilds are kept only for structural changes such as entering a different slot path or receiving a different part set.
- Made the middle preview image state-driven.
  - The preview control now reads the current composed texture state while drawing instead of holding a stale texture reference.
  - This prevents the preview from disappearing after quick-mod install/remove applies a new composed texture.
- Updated quick-mod slot clearing.
  - `QuickMod.ClearSlot` now accepts an optional callback.
  - Returned quick-mod items call the callback from the Barotrauma spawn queue when available.
  - A synchronous fallback still triggers the callback if no return spawn was queued.
- Updated quick-mod install/remove flow.
  - Quick-mod changes now synchronize from the original `ItemContainer`, prune invalid selections, save state, clear the applied signature, and apply the composed weapon sprite through one shared finish path.
  - The C# right-panel refresh updates only the active part controls instead of reopening the whole GunSmith UI through the original `DeepGunsmithSetPart` hook return path.
- Updated GunSmith inventory availability checks.
  - Part lookup now excludes the active weapon's own `OwnInventory`, so attachments already mounted in quick-mod slots are not counted as spare parts.
  - Player-carried parts outside the active weapon can still be found, including parts inside other nested carried containers.
- Added quick-mod UI sync for external ItemContainer edits.
  - Manual drag/drop changes made directly in the original `ItemContainer` now update the composed weapon and right-side GunSmith part status without polling or reopening the UI.

## Notes

- V1.3.1 does not add new quick-mod mappings or new weapon support.
- The HK416 quick-mod bridge still uses real contained items for Barotrauma original XML behavior.
- Deep-mod structural parts continue to use the existing GunSmith inventory and saved-state path.
